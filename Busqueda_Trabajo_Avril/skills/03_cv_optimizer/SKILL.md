# Skill 03: CV Optimizer

## Propósito

Adaptar el CV de Avril para maximizar la relevancia con cada vacante específica, destacando la experiencia y skills que más importan para ese rol.

## Cuándo Usar

- Encontraste una vacante que te interesa
- Quieres aplicar a una empresa específica
- Necesitas una versión del CV para un evento/networking

## Input Requerido

- Job description completa
- Nombre de la empresa
- Rol específico
- Palabras clave del job description

## Output

- CV adaptado con secciones reordenadas/priorizadas
- Lista de keywords a incluir
- Sugerencias de cómo reformular experiencias

## Estrategia de Adaptación

### 1. Análisis de Keywords

Extraer del job description:
- Skills técnicas requeridas
- Experiencias valoradas
- Industria/mercados mencionados
- Herramientas específicas
- Soft skills deseadas

### 2. Reordenar Secciones

Priorizar lo que la vacante valora:

**Si el rol valora marketing digital:**
1. Experiencia en Growix SA (community management, contenido)
2. Stack de herramientas (Canva, Photoshop, Meta)
3. Formación en Negocios Internacionales
4. Idiomas (inglés B2)

**Si el rol valora comercio internacional:**
1. Formación en Negocios Internacionales
2. Experiencia multi-país en Growix SA
3. Idiomas (inglés B2)
4. Stack de herramientas

**Si el rol valora diseño/branding:**
1. Stack de diseño (Photoshop, Illustrator, Canva, AutoCAD)
2. Portafolio visual
3. Experiencia en Growix SA (contenido visual)
4. Formación

### 3. Reformular Bullet Points

Template:
```
[Acción concreta] + [Herramienta/método] + [Resultado medible]
```

Ejemplos:

**Original genérico:**
"Community Manager en Growix SA"

**Optimizado para Marketing Digital:**
"Gestioné comunidades online en 3 países (EC/CO/USA), 
creando 15+ piezas de contenido semanales que aumentaron 
el engagement orgánico 40% en 3 meses"

**Optimizado para Comercio Exterior:**
"Coordiné estrategia de comunicación para mercados 
internacionales (EC/CO/USA), adaptando mensajes a 
culturas locales y regulaciones de cada país"

**Optimizado para Diseño:**
"Diseñé identidad visual y contenido para marca de 
autopartes internacional usando Adobe Suite y Canva, 
manteniendo coherencia de marca en 3 mercados"

## Checklist de Calidad

- [ ] ¿Cada bullet tiene acción + herramienta + resultado?
- [ ] ¿Las keywords del job description aparecen en el CV?
- [ ] ¿La sección más relevante para el rol está primero?
- [ ] ¿No hay palabras genéricas ("proactiva", "apasionada")?
- [ ] ¿El CV cabe en 1 página?
- [ ] ¿La tipografía es legible y profesional?
